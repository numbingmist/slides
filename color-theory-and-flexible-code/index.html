OKLCH и WCAG

Разница по L 45% и выше ~ попадание в АА

// цвет фона
--bg: oklch(L C H)
// цвет элемента в зависимости от темы
--contrast: oklch(from var(--bg) calc(l +/- 0.45) c h)

clamp(min, val, max)

Задаёт значение в диапазоне между min и max.
Вычисляется как: max(MIN, min(VAL, MAX)).

Авто-подбор цвета текста
Светлый фон → тёмный текст
Темный фон clamp(0, (l - 0.6) * -1, 1)
Тёмный фон → белый текст
// при -1 контраст провалится в середине диапазона на сером фоне
// -100 мягкая ступенька, -1000 жесткая ступенька
color: oklch(from var(--bg) clamp(0, (l - 0.6) * -100, 1) 0 h)

contrast-color(val)

Контраст · Задачи

  • Подбор контрастного цвета (текст/иконки/...).
  • Автоподбор контрастного цвета через CSS функции.
  • Один вычисляемый токен на светлую/темную темы.
  • Корректировка существующих токенов.

Контраст · Шпаргалка

  • oklch() + from + calc() + L = настраиваемый контраст.
  • clamp() - помощник в автоподборе (учитывайте пороги).
  • contrast-color() - нативный автоподбор (сырой).
  • Определитесь, в чем вы считаете L (число или процент).
  • ИИ просите, чтобы текст проходил проверки по WCAG.

Функции

calc(expression)

Даёт возможность рассчитать значения свойств CSS
во время их определения

calc(var(--opacity) + 0.5)

from

Создает новый цвета из заданного
через сохранение или коррекцию каналов оригинального цвета

oklch(from var(--base-color) l c 300 / 0.5)

color-mix()

Смешивает два цвета в заданном пространстве
и указанных пропорциях

color-mix(in oklab, white 25%, blue 75%)

color-mix(in oklch, ...) старая проблема

Раньше смешивание зеленых и синих оттенков в oklch выдавало желтизну. Поэтому использовали color-mix(in oklab, ...).
Сейчас в последних версиях браузеров работает корректно. Фиксы на уровне движков, поэтому для старых стоит использовать как раньше color-mix(in oklab, ...).

Ось 1 · Светлота

Светлее, темнее, воздушнее

Светлота отвечает за «вес» цвета. Она же — главный параметр, от которого зависит читаемость текста на фоне.

светлее → l ↑
темнее → l ↓
воздушнее → l ↑ + c ↓
тяжелее → l ↓ + c ↑
прозрачнее → l ↑ + alpha ↓
глубже → l ↓ + c ↑
Ось 2 · Насыщенность

Ярче, бледнее, спокойнее

Насыщенность — это «громкость» цвета. Один и тот же оттенок при разной c звучит как крик или как шёпот.

ярче → c ↑
бледнее → c ↓
сочнее → c ↑ + l ~ 55–65%
спокойнее → c ↓
пыльнее → c ↓ + l ↑ + h в тёплую
кислотнее → c ↑↑ + l ~ 60–70%
благороднее → c ↓ + l ↓
дешевле → c ↑↑ + l ~ 50%
Ось 3 · Оттенок

Теплее, холоднее, золотистее

Оттенок — это «характер» цвета. Он двигает цвет по кругу: от красного через жёлтый, зелёный, синий и обратно.

теплее → h к 30–60°
холоднее → h к 200–260°
розовее → h ~ 340°
зеленее → h ~ 140°
золотистее → h ~ 70–85° + l ↑
морской → h ~ 200° + c ~ 0.10
землистее → h ~ 70° + c ↓ + l ↓
ядовитее → h ~ 100–130° + c ↑↑
Ось 4 · Контраст и отношения

Мягче, строже, дороже

Эти слова описывают не отдельный цвет, а отношения между цветами в интерфейсе — разницу светлот, радиусы, тени.

контрастнее → разница l между элементами ↑
мягче → разница l ↓ + c ↓
строже → c ↓ + h монохром + радиус ↓
игривее → h сдвиг + c ↑ + радиус ↑
дороже → c ↓ + тень в тон + радиус ↑
дешевле → c ↑ + тень серая + радиус ↓
агрессивнее → c ↑↑ + контраст ↑ + h красный
дружелюбнее → c ↓ + l ↑ + h тёплый
Ось 5 · Характер и стиль

Минималистичнее, винтажнее, футуристичнее

Эти слова — про целое настроение интерфейса. Они складываются из нескольких параметров сразу, а не из одного.

минималистичнее → c ↓ + контраст ↓ + узкая палитра
винтажнее → c ↓ + l ↑ + h в тёплый
современнее → c ~ 0.15 + h монохром + тень в тон
ретро → h ~ 40–60° + c ↓ + l ~ 70%
футуристичнее → h ~ 200–280° + c ↑ + контраст ↑
натуральнее → h ~ 60–120° + c ↓
техно → h ~ 200° + c ↑ + монохром
Ось 6 · Метафоры

Как закат, как море, как золото

Самый человеческий уровень. Здесь эмоция — это образ, а образ — это конкретная точка в цветовом пространстве.

как закат → h ~ 20–40° + l ~ 65% + c ~ 0.15
как море → h ~ 200° + c ~ 0.12 + l ~ 60%
как мох → h ~ 100° + c ~ 0.06 + l ~ 45%
как вино → h ~ 350° + c ~ 0.15 + l ~ 30%
как кровь → h ~ 25° + c ~ 0.25 + l ~ 40%
как небо → h ~ 220° + c ~ 0.08 + l ~ 80%
как золото → h ~ 70° + c ~ 0.15 + l ~ 70%
