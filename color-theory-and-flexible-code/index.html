Цвет · Шпаргалка

  • Цветовое пространство выбирается под задачу.
  • oklch() самые гибкие вычисления с результатом, приближенным к восприятию глазом.

Зависимые цвета и гармонии

Включаем гармонию

Все классно, но...

  • У вас уже цвета не в oklch()
  • Старая ДС
  • Внешняя ДС, к изменению которой нет доступа

from = новые возможности

--base: #004B95;
oklch(from var(--base) l c h)
oklch(from var(--base) calc(l + 0.2) c h)
oklch(from var(--base) l 0.3 h)
oklch(from var(--base) l c calc(h - 200))
oklch(from var(--base) l c h / 0.5)

Нюансы WCAG

  • Не учитывает размер и начертание
  • Не учитывает жирность
  • Плохо работает для темных тем
  • Новый алгоритм APCA рассматривается как основа WCAG 3.0
OKLCH и WCAG

OKLCH и WCAG

Разница по L 45% и выше ~ попадание в АА

// цвет фона
--bg: oklch(L C H)
// цвет элемента в зависимости от темы
--contrast: oklch(from var(--bg) calc(l +/- 0.45) c h)

clamp(min, val, max)

Задаёт значение в диапазоне между min и max.
Вычисляется как: max(MIN, min(VAL, MAX)).

Авто-подбор цвета текста
Светлый фон → тёмный текст
Темный фон clamp(0, (l - 0.6) * -1, 1)
Тёмный фон → белый текст
// при -1 контраст провалится в середине диапазона на сером фоне
// -100 мягкая ступенька, -1000 жесткая ступенька
color: oklch(from var(--bg) clamp(0, (l - 0.6) * -100, 1) 0 h)

contrast-color(val)

Контраст · Задачи

  • Подбор контрастного цвета (текст/иконки/...).
  • Автоподбор контрастного цвета через CSS функции.
  • Один вычисляемый токен на светлую/темную темы.
  • Корректировка существующих токенов.

Контраст · Шпаргалка

  • oklch() + from + calc() + L = настраиваемый контраст.
  • clamp() - помощник в автоподборе (учитывайте пороги).
  • contrast-color() - нативный автоподбор (сырой).
  • Определитесь, в чем вы считаете L (число или процент).
  • ИИ просите, чтобы текст проходил проверки по WCAG.

Темы

Тема сводится к...

Которые могут вычисляться:
  • из параметров
  • from
  • color-mix()
  • ваша фантазия

Токены из базовых параметров 

      :root {

        --theme-l: 0.65;

        --theme-c: 0.25;

        --theme-h: 305;

        --theme-angle: 45; // угол цветовой гармонии

      }

Из которых можно собрать все остальное

// hue для цветовой гармонии
      :root {

        --hue1: var(--theme-h);

        --hue2: calc(var(--theme-h) + var(--theme-angle));

        --hue3: calc(var(--theme-h) - var(--theme-angle));

      }
// сами акцентные цвета
        :root {

          --theme-accent: oklch(var(--theme-l) var(--theme-c) var(--theme-hue1));

          --theme-accent-2: oklch(var(--theme-l) var(--theme-c) var(--theme-hue2));

          --theme-accent-3: oklch(var(--theme-l) var(--theme-c) var(--theme-hue3));

        }

Получаем
тему этих слайдов

Можно собрать на from

      :root {

        --base: #F637C6;


        --accent-soft: oklch(from var(--base) calc(l + 15%) calc(c * 0.6) h);

        --accent-deep: oklch(from var(--base) calc(l - 15%) c h);

      }
Вся тема из одного OKLCH + from

Меняем только --base — палитра пересчитывается через oklch(from ...).

Можно собрать на color-mix()

      :root {

        --bg: #0E1016;

        --accent: #C08BFF;

        --bg-30: color-mix(in oklab, var(--accent) 30%, var(--bg));

      }

Магия

Теория цвета
и практики гибкого кода

Один токен меняет всё: градиент, булеты, подсветки, кнопку и аватар.

  • Цвет — это три числа: l, c, h
  • Гармония — это правила сдвига по оттенку
  • Тема — это один токен и его производные
